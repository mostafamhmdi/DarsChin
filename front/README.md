# پنل سازندهٔ درخواست زمانبندی هوشمند

یک پنل **React + Vite** با رابط کاملاً **فارسی / RTL** و تم **دارک Glassmorphism** برای ساخت، اعتبارسنجی و ارسال درخواست زمانبندی کلاسها به یک API واحد.

طبق تصمیم اولیه:

| بخش | وضعیت |
| --- | --- |
| `teachers` | ✅ قابل ویرایش توسط کاربر |
| `courses` | ✅ قابل ویرایش توسط کاربر |
| `conflicts` | ✅ قابل ویرایش توسط کاربر |
| `slots` | 🔒 ثابت در کد، فقط خواندنی |
| `config` | 🔒 ثابت در کد، فقط خواندنی |
| ارسال | `POST` به `http://localhost:8000/schedule` بهصورت پیشفرض |

---

## ✨ قابلیتها

- **دشبورد نمای کلی** با آمار زنده، ماتریس جریمهٔ اسلاتها، رتبهبندی اولویت اساتید و خلاصهٔ تداخلها.
- **ویرایشگر اساتید**: نام، شناسه، اولویت ۱ تا ۵ و روزهای مجاز ۰ تا ۴؛ با تشخیص شناسهٔ تکراری و بهروزرسانی خودکار ارجاع دروس هنگام تغییر `id`.
- **ویرایشگر دروس**: نام، شناسه، استاد، تعداد جلسات، طول جلسه، ترم، مقطع و رشته؛ با محاسبهٔ ساعت آموزشی هفتگی.
- **ویرایشگر تداخلها**: افزودن جفت دروس، جلوگیری از تداخل تکراری/خودی، و نمایش **ماتریس تداخل**.
- **دادههای ثابت**: نمایش ۴۰ اسلات (۵ روز × ۸ بازه)، راهنمای جریمهها و `config` بهصورت فقط خواندنی.
- **اعتبارسنجی کامل** پیش از ارسال: یکتا بودن شناسهها، وجود استاد مرجع، بازههای عددی، روزهای مجاز، جفت تداخلها و ارجاعات معتبر.
- **پیشنمایش محمولهٔ نهایی** بهصورت JSON رنگیشده + نسخهٔ `cURL`، همراه با کپی، دانلود و بازگردانی به دادهٔ اولیه.
- **ارسال واقعی** با `fetch`، هدر `Content-Type: application/json`، تایماوت ۳۰ ثانیه و نمایش پاسخ بکاند.
- **حالت نمایشی (Mock)** برای تست بدون بکاند؛ در پیشنمایش زندهٔ آرنا بهصورت خودکار فعال میشود.
- اعلانها (Toast)، دیالوگ تأیید حذف/بازگردانی، طراحی واکنشگرا، فونت محلی **Vazirmatn Variable** و بدون وابستگی به CDN.

## 🚀 اجرا

```bash
cd scheduler-panel
npm install
npm run dev
```

پیشفرض روی `http://localhost:5173` بالا میآید.

### اتصال به بکاند واقعی

1. بکاند خود را روی پورت ۸۰۰۰ اجرا کنید تا `POST http://localhost:8000/schedule` در دسترس باشد.
2. در تب **«محموله و ارسال»** گزینهٔ **«بکاند زنده»** را انتخاب کنید.
3. دکمهٔ **«ارسال درخواست»** را بزنید.

آدرس از متغیر محیطی هم قابل تغییر است:

```bash
cp .env.example .env
# سپس VITE_API_URL را تغییر دهید
```

> ⚠️ اگر فرانت و بکاند روی originهای متفاوت اجرا شوند، بکاند باید هدرهای CORS و متد `POST` را مجاز کند. نمونه:
>
> ```http
> Access-Control-Allow-Origin: *
> Access-Control-Allow-Methods: POST, OPTIONS
> Access-Control-Allow-Headers: Content-Type, Accept, X-Client
> ```

### تست بدون بکاند

دو راه وجود دارد:

```bash
# راه ۱: بکاند نمایشی مستقل روی پورت ۸۰۰۰
npm run mock:api

# راه ۲: حالت نمایشی داخلی Vite
# در تب «محموله و ارسال» گزینهٔ «حالت نمایشی» را انتخاب کنید
```

در حالت نمایشی، درخواست به `/__mock/schedule` ارسال میشود که توسط middleware داخل `vite.config.js` پاسخ میدهد. این مسیر هم در `npm run dev` و هم در `npm run preview` کار میکند.

> در پیشنمایش زندهٔ آرنا، چون مرورگر کاربر به `localhost` داخل سندباکس دسترسی ندارد، حالت نمایشی بهصورت پیشفرض فعال است. کافی است برای اتصال واقعی، «بکاند زنده» و آدرس قابلدسترس بکاند خود را وارد کنید.

## 📦 ساختار payload

```json
{
  "teachers": [],
  "courses": [],
  "slots": [],
  "conflicts": [],
  "config": {
    "time_limit_sec": 30,
    "num_workers": 8
  }
}
```

- `teachers`, `courses`, `conflicts` از state رابط کاربری میآیند.
- `slots` و `config` مستقیماً از `src/data/staticData.js` خوانده میشوند و هیچ فیلد ویرایشی برای آنها وجود ندارد.

### نگاشت روزها

| --- | --- |

| `1` | یکشنبه |
| `2` | دوشنبه |
| `3` | سهشنبه |
| `4` | چهارشنبه |

## 🔧 شخصیسازی

- تغییر دادهٔ اولیه: `src/data/staticData.js`
- تغییر آدرس پیشفرض API: `.env` → `VITE_API_URL`
- تغییر قوانین اعتبارسنجی: `src/lib/validation.js`
- تغییر رنگها، فاصلهها و تم: `src/styles.css` (متغیرهای `:root`)
- افزودن فیلد جدید به فرمها: کامپوننت مربوطه + `validation.js` + در صورت نیاز `staticData.js`

---

## 📝 نکات پیادهسازی

- شناسهٔ استاد یا درس هنگام ویرایش، ارجاعات وابسته را بهصورت خودکار اصلاح میکند تا `teacher_id` و `course_a/course_b` معتبر بمانند.
- حذف استاد، دروس مرتبط و تداخلهای آن دروس را نیز پاک میکند و پیش از آن دیالوگ تأیید نشان میدهد.
- دکمهٔ ارسال تا زمان معتبر شدن کامل محموله غیرفعال است.
- پاسخ بکاند در همان صفحه، همراه با `status`, `requestId` و خلاصهٔ تعداد موجودیتها نمایش داده میشود.
- هیچ کتابخانهٔ CSS خارجی، فونت CDN یا تصویر remote استفاده نشده است؛ خروجی کاملاً مستقل و باندلشده است.
